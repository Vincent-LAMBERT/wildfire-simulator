# Wildfire Simulator :fire:

This is a project aimed to practice Java and Spring Boot by simulating the spread of a wildfire in a forest. The application consists of a backend built with Spring Boot and a frontend built with Angular.

### Installation steps

1. Clone the repository: `git clone ...`

##### Spring Boot backend

2. Navigate to the project directory: `cd wildfire-simulator`
3. Build the project using Maven: `mvn clean install`

##### Angular frontend

4. Navigate to the angular directory: `cd angularclient`
5. Build the Angular application: `npm install`

### Running the application

4. Run the backend in the project directory: `cd wildfire-simulator` and then `mvn spring-boot:run`
4. Run the frontend in the angular directory: `cd angularclient` and then `ng serve`
5. The application will start on `http://localhost:4200`. You can directly access the backend API at `http://localhost:8081`.
